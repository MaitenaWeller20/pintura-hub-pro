# Validación obligatoria de receptores por padrón de ARCA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Verificar en el padrón vigente de ARCA todo receptor con CUIT, usar la identidad oficial en el comprobante y bloquear antes de reservar numeración o pedir CAE cuando la consulta no pueda completarse.

**Architecture:** La credencial X.509 existente obtiene un ticket WSAA separado para `ws_sr_constancia_inscripcion`. Un adaptador server-only consulta `getPersona_v2`, valida una respuesta desconocida y devuelve un receptor canónico. El diálogo hace una consulta anticipada para revisión, pero preview y emisión vuelven a consultar en servidor; sólo esa segunda respuesta alimenta el snapshot. La exigencia se activa por emisor y ambiente después de una prueba administrativa real, sin caché de contribuyentes ni bypass.

**Tech Stack:** PostgreSQL/Supabase CLI, TanStack Start, React 19, TypeScript 5.8, Zod 3, `@arcasdk/core@2.0.0`, Vitest 4, Vite 8 y Vercel Node.js/Fluid Compute.

**Spec:** `docs/superpowers/specs/2026-08-26-validacion-padron-arca-design.md`

## Global Constraints

- Trabajar sólo en el worktree aislado y conservar intactos los cambios ajenos del árbol principal.
- No aplicar migraciones a producción, desplegar, activar el padrón productivo ni emitir un CAE real durante la implementación automatizada.
- No llamar a ARCA desde tests. Toda respuesta de padrón será un fixture inyectado; cualquier prueba manual real se hará después en homologación y con autorización operativa.
- Mantener `@arcasdk/core` fijado exactamente en `2.0.0`; el servicio es `ws_sr_constancia_inscripcion` y el método vigente es `getPersona_v2`, según el manual ARCA V4.1 de marzo de 2026.
- Reutilizar el certificado actual. No generar un segundo certificado ni almacenar un segundo par de claves; WSAA separa el ticket por CUIT emisor, servicio y ambiente.
- Ejecutar el SDK SOAP sólo en runtime Node.js/Fluid Compute. No mover esta integración a Edge.
- Desplegar la migración con `padron_validacion_activa=false`; nunca activar una credencial automáticamente por deploy, seed o backfill.
- No inferir CUIT/CUIL/CDI por longitud. Sólo consultar un CUIT explícito o un `cuit_dni` que pase `cuitValido`; el resto conserva el circuito actual.
- No cachear ni persistir la respuesta completa de un contribuyente. El snapshot guarda únicamente identidad fiscal necesaria, domicilio normalizado y `verificadoArcaAt`.
- Consultar de nuevo en servidor antes de `RESERVAR` y `FECAESolicitar`. Ante cualquier fallo obligatorio no hay reserva, request iniciado ni CAE.
- Las notas de crédito conservan exactamente el receptor del snapshot original y no vuelven a consultar datos vivos.
- El mensaje de caída debe ser exactamente: “ARCA está caído y no pudimos verificar el CUIT. No se emitió ningún comprobante. Intentá nuevamente en otro momento.” Nunca mostrar “ARCA no responde”.
- Los errores públicos usan códigos cerrados. Nunca transportar ni registrar claves, certificados, tickets, XML/SOAP, SQL, stack traces ni mensajes crudos del SDK.
- Toda acción server con service role autentica y autoriza primero. La tabla `credenciales_arca` sigue sin grants ni policies para `anon` o `authenticated`.
- Crear la migración exclusivamente con `supabase migration new padron_validacion_arca`; usar el nombre impreso por la CLI y no inventar timestamps.
- Cada tarea sigue RED → GREEN → refactor → pruebas focalizadas → commit local. No hacer amend, rebase, squash ni force-push de historia publicada.

~~~sql
ALTER TABLE public.credenciales_arca
  ADD COLUMN padron_probado_at timestamptz,
  ADD COLUMN padron_validacion_activa boolean NOT NULL DEFAULT false,
  ADD COLUMN padron_ultimo_error_codigo text,
  ADD COLUMN padron_ultimo_error_at timestamptz,
  ADD CONSTRAINT ck_credenciales_arca_padron_codigo
    CHECK (
      padron_ultimo_error_codigo IS NULL OR
      padron_ultimo_error_codigo IN (
        'PADRON_ARCA_CAIDO',
        'PADRON_NO_AUTORIZADO',
        'PADRON_CONFIG_INVALIDA',
        'CUIT_INVALIDO',
        'CUIT_NO_ENCONTRADO',
        'CUIT_INACTIVO',
        'RESPUESTA_PADRON_INVALIDA',
        'CONDICION_FISCAL_INCOMPATIBLE'
      )
    ),
  ADD CONSTRAINT ck_credenciales_arca_padron_activo_probado
    CHECK (NOT padron_validacion_activa OR padron_probado_at IS NOT NULL),
  ADD CONSTRAINT ck_credenciales_arca_padron_error_completo
    CHECK (
      (padron_ultimo_error_codigo IS NULL) =
      (padron_ultimo_error_at IS NULL)
    );

CREATE FUNCTION public.reset_padron_arca_por_credencial()
RETURNS trigger
LANGUAGE plpgsql
SECURITY INVOKER
SET search_path = ''
AS $$
BEGIN
  IF OLD.arca_key_enc IS DISTINCT FROM NEW.arca_key_enc
     OR OLD.arca_cert_enc IS DISTINCT FROM NEW.arca_cert_enc
     OR OLD.ambiente IS DISTINCT FROM NEW.ambiente THEN
    NEW.padron_probado_at := NULL;
    NEW.padron_validacion_activa := false;
    NEW.padron_ultimo_error_codigo := NULL;
    NEW.padron_ultimo_error_at := NULL;
  END IF;
  RETURN NEW;
END;
$$;

CREATE TRIGGER trg_credenciales_arca_reset_padron
  BEFORE UPDATE OF arca_key_enc, arca_cert_enc, ambiente
  ON public.credenciales_arca
  FOR EACH ROW
  EXECUTE FUNCTION public.reset_padron_arca_por_credencial();

CREATE FUNCTION public.reset_padron_arca_por_cuit_emisor()
RETURNS trigger
LANGUAGE plpgsql
SECURITY INVOKER
SET search_path = ''
AS $$
BEGIN
  IF OLD.cuit IS DISTINCT FROM NEW.cuit THEN
    UPDATE public.credenciales_arca
    SET
      padron_probado_at = NULL,
      padron_validacion_activa = false,
      padron_ultimo_error_codigo = NULL,
      padron_ultimo_error_at = NULL
    WHERE emisor_id = NEW.id;
  END IF;
  RETURN NEW;
END;
$$;

CREATE TRIGGER trg_emisores_reset_padron_por_cuit
  AFTER UPDATE OF cuit
  ON public.emisores
  FOR EACH ROW
  EXECUTE FUNCTION public.reset_padron_arca_por_cuit_emisor();

REVOKE ALL ON FUNCTION public.reset_padron_arca_por_credencial() FROM PUBLIC;
REVOKE ALL ON FUNCTION public.reset_padron_arca_por_cuit_emisor() FROM PUBLIC;
~~~

export async function ejecutarPruebaActivacionPadron(
  input: EntradaPruebaActivacionPadron,
) {
  if (input.mockMode) {
    throw crearErrorFiscalUsuario("PADRON_CONFIG_INVALIDA");
  }
  const ahora = input.ahora();
  if (!Number.isFinite(ahora.getTime())) {
    throw crearErrorFiscalUsuario(
      "PADRON_CONFIG_INVALIDA",
    );

  const fecha = ahora.toISOString();
  try {

    if (receptor.cuit !== input.cuitEmisor) {
      throw crearErrorFiscalUsuario(
        "RESPUESTA_PADRON_INVALIDA",
      );
    }
    await input.registrarExito(fecha);
    return {
      cuit: receptor.cuit,
      razon_social: receptor.razonSocial,
      probado_at: fecha,
    };
  } catch (cause) {
    const marcado = codigoErrorFiscalUsuario(cause);
    const codigo = esCodigoErrorPadronArca(marcado)
      ? marcado
      : "PADRON_CONFIG_INVALIDA";
    try {
      await input.registrarFallo({ codigo, fecha });
    } catch {
      throw crearErrorFiscalUsuario(
        "PADRON_CONFIG_INVALIDA",
      );
    }
    throw crearErrorFiscalUsuario(codigo);
  }
}

export function cuitParaConsulta(input: {
  receptor: ReceptorFormulario;
  cliente: ClienteComercialFiscal;
  favoritos: ReceptorFiscalFavorito[];
}): string | null {
  if (input.receptor.origen === "CLIENTE_COMERCIAL") {
    return cuitValido(input.cliente.documento)
      ? input.cliente.documento!.replace(/\D/g, "")
      : null;
  }
  if (input.receptor.origen === "FAVORITO") {
    const favorito = input.favoritos.find(
      (item) =>
        item.id === input.receptor.receptor_fiscal_id,
    );
    return favorito?.tipo_documento === "CUIT" &&
      cuitValido(favorito.numero_documento)
      ? favorito.numero_documento.replace(/\D/g, "")
      : null;
  }
  if (
    input.receptor.origen === "MANUAL" &&
    input.receptor.tipo_documento === "CUIT" &&
    cuitValido(input.receptor.numero_documento)
  ) {
    return input.receptor.numero_documento.replace(
      /\D/g,
      "",
    );
  }
  return null;
}
~~~
